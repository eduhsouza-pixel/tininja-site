Comandos do Firewall do Windows

Os comandos do Short “Aprenda Firewall do Windows em 2 minutos”, na ordem do diagnóstico: primeiro a porta, depois a etiqueta da rede, depois a regra. Rodam no PowerShell. Os que mudam alguma coisa pedem o PowerShell aberto como administrador.

Troque o IP 10.78.0.10 e as portas pelos do seu servidor. Esses foram os da bancada de laboratório gravada no vídeo (Windows 11 e Windows Server 2025).

1 A porta

No PC que não conecta

O ping pode estar bloqueado e o servidor estar perfeito. Teste a porta do serviço que você precisa (53 é DNS, 445 é pasta compartilhada, 3389 é área de trabalho remota).

ping -n 2 10.78.0.10
Test-NetConnection 10.78.0.10 -Port 53

Leu TcpTestSucceeded : True? O servidor está vivo e o serviço responde. Se o ping falhou, o problema é só o ping, não a rede.

2 A etiqueta da rede

No servidor

O Windows põe uma de três etiquetas em cada rede: domínio (achou o controlador), privada (marcada como confiável) ou pública. Rede que ele não reconhece vira pública, a mais fechada.

Get-NetConnectionProfile | Select-Object InterfaceAlias, NetworkCategory

Public num servidor da empresa costuma ser a pegadinha: servidor novo, rede sem gateway, controlador que não respondeu no boot.

3 A regra

No servidor, PowerShell como administrador

A regra que deixa o Windows responder ao ping se chama FPS-ICMP4-ERQ-In. Veja se ela está ligada:

Get-NetFirewallRule -Name FPS-ICMP4-ERQ-In | Select-Object Name, Enabled, Profile

Ligue só essa regra:

Enable-NetFirewallRule -Name FPS-ICMP4-ERQ-In

Nunca rode Enable-NetFirewallRule sem o nome da regra. Sem parâmetro, ele liga todas as regras do firewall do computador. A própria documentação da Microsoft avisa.

Liberar só o que o serviço precisa

O certo é abrir só a porta do serviço, e só para a rede da empresa. Exemplo para um sistema na porta TCP 8080 (troque o nome e a porta):

New-NetFirewallRule -DisplayName "Sistema" -Direction Inbound -Protocol TCP -LocalPort 8080 -RemoteAddress LocalSubnet -Action Allow

Se a rede é sua e é confiável, dá para trocar a etiqueta para privada. O perfil de domínio não se escolhe à mão: ele aparece quando o computador do domínio acha o controlador.

Set-NetConnectionProfile -InterfaceAlias "Ethernet" -NetworkCategory Private

O que não fazer

Não desligue o firewall inteiro. O ping volta, mas junto abre todas as portas do servidor. A Microsoft recomenda não desligar o Windows Firewall: você perde a proteção e outros recursos que dependem dele.

O comando que todo mundo já usou para testar, e que não deve ficar assim: Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False
