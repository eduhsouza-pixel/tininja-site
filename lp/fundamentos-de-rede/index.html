Como você vai trabalhar

  1. Pergunta: o que exatamente parou, para quem?
  2. Evidência: a mensagem, a configuração, o resultado do teste.
  3. Hipótese: nome, endereço, caminho ou serviço?
  4. Teste: o menor teste que separa uma hipótese da outra.
  5. Conclusão: o que falhou, com a prova, ou "ainda não sei".

Antes de entrar

Preciso ter servidor ou laboratório em casa?

Não. O Módulo 0 só pede um editor de texto. No Módulo 1 você monta o laboratório no VirtualBox, no seu próprio PC, com a aula passo a passo.

Nunca mexi com rede. Vou acompanhar?

Sim. O curso começa pelo método e explica cada conceito (endereço, máscara, gateway, DNS, DHCP) a partir de um sintoma de chamado, sem pressupor experiência. O que ele pressupõe é que você já use o Windows no dia a dia: o curso não ensina sistema operacional do zero.

Serve para quem estuda para o CCNA ou quer uma formação completa?

O Fundamentos de Rede não segue o roteiro da prova da Cisco nem usa equipamento Cisco. Ele ensina a base que toda rede usa (endereço, máscara, gateway, DNS e DHCP) no Windows, em laboratório, a partir de sintomas de chamado. Quem estuda para o CCNA aproveita essa base, mas precisa de material próprio para a prova. Também não é uma formação completa de infraestrutura: é a base de rede que os assuntos mais avançados, como o Active Directory, pressupõem. O bônus de Virtualização acrescenta um caso de servidor e máquinas virtuais, mas não transforma o curso numa formação completa.
