O método

A diferença não é decorar o assistente. É saber o que cada campo muda.

Como costuma ser

  • Segue um tutorial antigo e a tela não bate com a sua.
  • Dá à VM toda a memória que sobrou, "para garantir".
  • Deixa o disco e a placa de rede no padrão porque "funciona".
  • Confia num snapshot como se fosse backup.

Como você vai trabalhar

  1. Lê o que a documentação oficial diz de cada campo.
  2. Começa a VM pequena, mede no Resumo e ajusta.
  3. Usa VirtIO e carrega os drivers na instalação do Windows.
  4. Sabe quando usar snapshot e quando usar backup.

Perguntas frequentes

Antes de entrar

Preciso ter um servidor?

Não. O Proxmox roda numa máquina virtual do VirtualBox, no seu próprio PC. A aula 2 monta essa VM passo a passo.

Preciso ter feito o Fundamentos de Rede?

Não é obrigatório. O curso pressupõe que você já entende endereço IP, máscara e gateway. A parte de rede da VM (bridge e VLAN) fica bem mais fácil com essa base, que é a do Fundamentos.

Meu Windows usa Hyper-V. Vai funcionar?

Para o Proxmox rodar VMs dentro do VirtualBox, o hipervisor do Windows precisa estar desligado. Com ele ligado, o VirtualBox não oferece a virtualização aninhada. A aula 2 mostra o que conferir.

Preciso de licença do Windows Server?

Não. O curso usa a ISO de avaliação que a Microsoft disponibiliza.

O ProxMenux é oficial do Proxmox?

Não. É uma ferramenta da comunidade, sem vínculo com a Proxmox Server Solutions. O módulo mostra como ler o script antes de instalar.
